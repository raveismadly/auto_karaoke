Как это работает

1. Загрузка аудиофайла

Загрузите MP3 или WAV файл песни, для которой хотите создать караоке.

2. Отделение вокала

Приложение использует Spleeter для разделения вокала и инструментов.

3. Распознавание текста

Whisper AI распознает слова из вокала и определяет их тайминги.

4. Синхронизация текста

Текст песни синхронизируется с инструментальной версией.

5. Создание караоке

Генерируется финальное видео с выделением текста в такт музыке.

Технические детали

Используемые технологии

Spleeter

Библиотека с открытым исходным кодом от Deezer для разделения музыкальных треков на отдельные стемы (вокал и инструменты).

# Установка Spleeter
pip install spleeter

# Разделение аудио
spleeter separate -p spleeter:2stems -o output input.mp3

Whisper AI

Система распознавания речи от OpenAI, способная транскрибировать аудио с высокой точностью и определять тайминги слов.

# Установка Whisper
pip install openai-whisper

# Распознавание речи
whisper audio.mp3 --model medium

FFmpeg

Набор инструментов для обработки мультимедийных файлов, используемый для объединения аудио, видео и текста в конечное караоке.

# Создание караоке видео
ffmpeg -i background.mp4 -i instrumental.wav \
-vf "subtitles=lyrics.srt:force_style='FontSize=24'" \
-c:a aac -strict experimental output.mp4

Python

Язык программирования, используемый для интеграции всех компонентов и обработки данных. Доступные библиотеки упрощают работу с аудио.

# Пример интеграции компонентов
import whisper
import subprocess

# Распознавание текста
model = whisper.load_model("medium")
result = model.transcribe("vocals.wav")

Требования к системе

Минимальные требования:

  • macOS 10.15 Catalina или новее
  • 4 ГБ оперативной памяти
  • 2 ГГц двухъядерный процессор Intel
  • 5 ГБ свободного места на диске
  • Интернет-соединение

Рекомендуемые требования:

  • macOS 12 Monterey или новее
  • 8 ГБ оперативной памяти
  • Apple Silicon (M1/M2) или Intel i5/i7
  • 10 ГБ свободного места на диске
  • Высокоскоростное интернет-соединение
Установка

Установка и использование

Шаги установки

  1. 1

    Загрузка приложения

    Скачайте последнюю версию AutoKaraoke с официального сайта или через Mac App Store.

  2. 2

    Установка зависимостей

    При первом запуске приложение автоматически установит необходимые компоненты (Python, FFmpeg и библиотеки).

  3. 3

    Настройка доступа

    Предоставьте приложению доступ к микрофону и файловой системе при запросе системы.

  4. 4

    Загрузка моделей

    При первом запуске будут загружены модели Spleeter и Whisper (около 2 ГБ данных).

Использование для разработчиков

# Клонирование репозитория
git clone https://github.com/user/autokaraoke.git
# Установка зависимостей
pip install -r requirements.txt
# Установка Spleeter
pip install spleeter
# Установка Whisper
pip install openai-whisper

Настройка переменных окружения

Для работы с API и внешними сервисами создайте файл .env в корне проекта:

# API ключи (опционально)
MUSIXMATCH_API_KEY=your_key_here
GENIUS_API_KEY=your_key_here

# Настройки Whisper
WHISPER_MODEL=medium
LANGUAGE=ru

Командная строка

Вы также можете использовать AutoKaraoke через командную строку:

# Создание караоке из аудиофайла
autokaraoke create --input song.mp3 --output karaoke.mp4 --style modern
# Извлечение только инструментальной версии
autokaraoke extract --input song.mp3 --output instrumental.wav --type instrumental
# Распознавание текста без создания видео
autokaraoke transcribe --input song.mp3 --output lyrics.srt --model large
